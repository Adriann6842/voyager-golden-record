## 🎬 How It Works

The Voyager Golden Record stores pictures the same way old television signals did. Each image is drawn as a series of horizontal lines. Brightness values become sound wave amplitudes. The decoder reads these audio samples, spots the calibration circle at the start of each image, and reconstructs the picture line by line.

For a full explanation, watch this video: [youtu.be/83TRij3igmE](https://youtu.be/83TRij3igmE)

## 🛠️ Troubleshooting

**Program won't start?**
Make sure your antivirus isn't blocking the download. Temporarily disable it, download again, then re-enable it.

**No images appear?**
Check that you're using a valid Golden Record audio file. The file should be in WAV or FLAC format. MP3 files may lose the encoded data.

**Audio plays but no image?**
The audio might be too quiet. Try increasing the volume or adjusting the gain setting in the program.

**Program crashes?**
Update your audio drivers. Restart your computer. Try running the program as administrator (right-click > Run as Administrator).
